Instrucciones

1. Cargá tus productos

En Base de datos agregá el costo real del producto, papel, tinta, amortización y merma.

2. Calculá el precio

Elegí un producto, indicá cantidad y gastos. El sistema calcula costo, margen, comisión, IVA y total.

3. Guardá el presupuesto

Completá el cliente y guardá la cotización. Queda almacenada en este dispositivo.

Esta versión funciona localmente con localStorage. Para sincronizar usuarios y dispositivos hay que conectar Firebase.
